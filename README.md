# Castronegro · Asistente del narrador

Asistente web para dirigir partidas de Hombre Lobo de Castronegro desde un solo móvil.

## Empezar

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # reglas del juego (Vitest)
npm run build    # comprobar tipos y construir
```

Para trabajar con Claude Code abre esta carpeta en VS Code y lanza `claude`: lee `CLAUDE.md` solo.
La beta original está en `prototipo/` (referencia, no se toca).
